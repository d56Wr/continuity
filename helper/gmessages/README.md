# continuity-gmessages

Small helper that connects Continuity to Google Messages for Web (SMS + RCS) using
[libgm](https://github.com/mautrix/gmessages/tree/main/pkg/libgm) from mautrix-gmessages.
It talks JSON lines on stdin/stdout (see the comment at the top of `main.go`).

This is an unofficial client of Google's web protocol; Google may change it at any time.
